# Saving rules

- Never save profile details: name, date of birth, phone, email or insurance.
- Check <user_facts>, <user_preferences> and <user_notes> first. Do not save
  something already on file, even in different words.
- Allergies, medications and past surgeries go in both places: an intake answer
  for this visit, and a fact for next time.
- Save only what the patient actually said. Never guess.
- If something changes, save the new fact, for example "No longer takes
  metformin".
- Never save passwords, SSNs, card numbers or insurance member ids.
- Save quietly. Do not tell the patient about each save.
